- **Duration mapping**: app "Ticks(N)" → `{duration:N, duration_unit:"t"}`; "Seconds(N)" → `"s"`; "Minutes(N)" → `"m"`.

## Architecture
New package `com.example.data.deriv` holding the real API (keeps the existing `data/websocket` fallback removed):
- `DerivRestClient.kt` (OkHttp): `GET /trading/v1/options/accounts` (list accounts + balances), `GET /wallet/v1/wallets` (optional), `POST /trading/v1/options/accounts/{id}/otp` (get trading WS url).
- `DerivMarketDataClient.kt` (OkHttp WebSocket → V1 public endpoint): `active_symbols` (discover/validate the 5 VIX markets + pip sizes), `ticks_history` + `ticks` streaming; emits `MarketState` flows (reuse existing model).
- `DerivTradingClient.kt` (per-account WS): `proposal` → `buy`, then `contract_update`/`contract_update_history` for settlement; `sell` to close; typed response matching by `req_id`/`echo_req`.
- `DerivAccountManager.kt`: holds live account list, active account (DEMO/REAL), and real balances; refreshes after settlements.

Replaced/removed: `DerivWebSocketService`'s synthetic fallback ticker and V3 URL; `SimulationEngine`'s local settlement + fake `10000.00 + netResult` balance write.
